# Mihomo sidecar

The Windows x86-64 installer bundles the unmodified MetaCubeX/mihomo v1.19.33
executable as a separate process. Its GPL-3.0 license and upstream source archive
are distributed alongside the executable. Source: https://github.com/MetaCubeX/mihomo/tree/v1.19.33

The official Windows AMD64 v1 archive SHA-256 is
`fb0b960eff568459502d4ebe53e9cca203053d86ec9024fe935f19615d74d9aa`.
Prepare the ignored build binary with `python scripts/prepare-mihomo.py`.
